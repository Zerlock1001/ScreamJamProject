# 画布工坊 · 轻量排版编辑器

一个自用的本地网页排版编辑器。无需数据库、无需安装前端依赖，全部代码、启动脚本和项目数据都在当前文件夹内。

## 启动

直接双击 **`启动.bat`**。

- 脚本会调用本机已有的 Node.js 启动一个只监听本机的网页服务，并自动打开浏览器。
- 默认地址：`http://127.0.0.1:5188/`（端口被占用时会自动换到下一个）。
- 项目数据保存在本文件夹的 `data/project.json`。
- 停止：关闭启动器窗口，或在窗口里按 `Ctrl+C`。

> 如果电脑没有 Node.js，`启动.bat` 会退回到直接打开 `index.html`。此模式仍可使用，但数据保存在浏览器本地存储中，而不是文件夹内。建议安装 Node.js 以获得完整功能。

## 功能

- **多页面**：新建、重命名、切换、删除页面；每个页面有独立布局。
- **共用素材库**：上传透明 PNG / WebP / SVG / GIF / JPEG；在所有页面共用。
- **点击添加**：点击素材卡片，图片出现在画面中央。
- **文字图层**：点击顶部「文字」添加；可双击修改内容，支持字体、字号加减、粗体和颜色。
- **直接编辑**：拖动移动、四角缩放、顶部圆点旋转；文字缩放会同步字号，无需输入坐标。
- **图层**：右侧图层列表拖动排序；支持显示/隐藏、锁定、删除。
- **撤销/重做**：最多保留 60 步布局和文字编辑操作。
- **自动保存**：修改后自动保存到 `data/project.json`。
- **预览**：全屏查看页面效果，可导出 PNG。
- **完整项目导入/导出**：JSON 中包含全部页面、图层和素材原图。
- **多窗口同步**：不同窗口打开同一地址时，通过 BroadcastChannel 加定时校验同步最新项目。
- **素材保留**：删除画布中的图层不会删除素材库里的原图片。

## 操作

| 操作 | 方法 |
| --- | --- |
| 添加文字 | 点击顶部「文字」，输入内容后点击空白处或按 `Ctrl+Enter` 完成 |
| 编辑文字 | 双击画布上的文字；`Esc` 取消本次修改 |
| 调整字体 / 字号 | 选中文字后，在右侧「文字设置」中选择字体、输入字号或点 `−` / `+` |
| 移动图层 | 直接在画布上拖动 |
| 缩放 | 拖动四角白色控制点；按住 `Shift` 等比缩放（文字图层始终等比并同步字号） |
| 旋转 | 拖动选框上方的圆点；按住 `Shift` 以 15° 吸附 |
| 调整层级 | 在右侧图层列表中上下拖动 |
| 缩放画布 | `Ctrl + 鼠标滚轮`，或底部缩放按钮 |
| 滚动画布 | 直接滚动鼠标滚轮 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` |
| 删除选中图层 | `Delete` |
| 取消选择 / 关闭弹窗 | `Esc` |
| 立即保存 | `Ctrl+S` |
| 适应窗口 | 底部缩放条右侧按钮，或 `Ctrl+0` |

## 数据与备份

- `data/project.json` 保存完整项目（素材以 Data URL 形式内嵌）。
- 建议定期使用右上角「导出」保存一个完整项目备份。
- 导入会替换当前项目，导入前会弹出确认。
- 所有读写都限制在本文件夹内；本地服务只绑定 `127.0.0.1`，不对局域网开放。
